# 🎰 幸运大抽奖 - PWA 小程序

## 项目说明

一个支持离线使用的积分抽奖 PWA 小程序，可以安装到手机主屏幕，像原生 App 一样使用。

## 功能特性

- 🎡 **转盘抽奖**：10个奖项，动画效果流畅
- 💎 **积分系统**：支持自定义充值、扫码充值
- 📱 **扫码充值**：调用摄像头扫描充值二维码
- ⚙️ **管理员后台**：修改奖品、概率、消耗积分
- 📊 **历史记录**：记录每次抽奖结果
- 🔒 **离线使用**：安装后无需网络也能使用
- 📲 **PWA 安装**：可添加到手机主屏幕

## 文件结构

```
抽奖小程序/
├── index.html          # 主页面
├── style.css           # 样式文件
├── app.js              # 业务逻辑
├── sw.js               # Service Worker（离线缓存）
├── manifest.json       # PWA 配置文件
└── README.md           # 使用说明
```

## 部署方式

### 方式一：本地测试（电脑浏览器）

1. 直接用浏览器打开 `index.html`
2. 注意：扫码功能需要在 HTTPS 环境下才能使用

### 方式二：手机使用（推荐）

#### 方案 A：使用静态网站托管

1. 将项目文件上传到以下任一平台：
   - GitHub Pages
   - Vercel
   - Netlify
   - 腾讯云静态网站托管
   - 阿里云 OSS

2. 确保通过 **HTTPS** 访问

3. 手机浏览器打开网址，按提示"添加到主屏幕"

#### 方案 B：本地局域网测试

1. 在电脑上安装一个本地服务器工具：

**Python 方式：**
```bash
# 进入项目目录
cd 抽奖小程序

# Python 3
python -m http.server 8080

# 或 Python 2
python -m SimpleHTTPServer 8080
```

**Node.js 方式：**
```bash
# 安装 serve
npm install -g serve

# 进入项目目录
cd 抽奖小程序

# 启动服务器
serve -l 8080
```

2. 确保手机和电脑在同一 WiFi 下

3. 手机浏览器访问：`http://电脑IP:8080`

4. 按浏览器提示"添加到主屏幕"

### 方式三：打包为 APK（高级）

使用工具将 PWA 打包为原生 App：
- [PWA Builder](https://www.pwabuilder.com/)
- [Capacitor](https://capacitorjs.com/)
- [Cordova](https://cordova.apache.org/)

## 使用说明

### 首次使用

1. 打开应用，初始积分为 0
2. 联系管理员充值积分（充值功能在管理员界面）
3. 设置每次抽奖消耗的积分（默认50）
4. 点击"开始抽奖"开始转盘

### 管理员设置

1. 点击右下角"⚙️ 管理员"
2. 输入密码：`admin123`
3. 可修改：
   - 奖品名称和内容
   - 各奖项基础概率（百分比，保留2位小数）
   - 默认抽奖消耗积分
   - 用户积分充值
4. 点击"保存并退出"保存所有设置

### 积分充值（管理员）

1. 进入管理员界面
2. **手动充值**：输入积分数量，点击"充值"
3. **图片识别充值**：
   - 点击"📷 上传图片识别"
   - 选择包含数字的图片（如转账截图、二维码等）
   - 系统自动识别图片中的数字
   - 弹出确认框，识别不准确可手动修改金额
   - 点击"确认充值"完成充值

### 添加到主屏幕

**iPhone (Safari)：**
1. 点击底部分享按钮
2. 选择"添加到主屏幕"
3. 点击"添加"

**Android (Chrome)：**
1. 点击右上角菜单（⋮）
2. 选择"添加到主屏幕"或"安装应用"
3. 点击"安装"

## 技术栈

- HTML5 + CSS3 + JavaScript（纯前端，无框架）
- PWA（Service Worker + Manifest）
- Tesseract.js（图片数字识别，CDN引入）
- localStorage（本地数据存储）

## 注意事项

1. **数据存储**：所有数据保存在浏览器 localStorage 中，清除浏览器数据会丢失
2. **离线使用**：安装 PWA 后，除图片识别功能外，其他功能可离线使用
3. **充值功能**：充值功能已移至管理员界面，需管理员登录后操作
4. **图片识别**：扫码充值通过上传图片识别数字，识别不准确可手动修改
